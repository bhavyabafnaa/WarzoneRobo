# Results pending regeneration

The pre-validity-fix CSV and HTML tables were removed because they were
generated by an invalid experiment pipeline. They remain available in Git
history for audit purposes, but must not be used as research evidence.

Generate corrected per-seed records and summary tables with:

```bash
python train.py --config configs/default.yaml --seeds 0 1 2 3 4
```

The command creates `training_runs.csv`, `benchmark_runs.csv`,
`training_results.csv`, `training_results.html`, `benchmark_results.csv` and
`benchmark_results.html` in this directory.
